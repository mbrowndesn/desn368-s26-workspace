A reflection on the design and development process behind Base Camp — a responsive field guide built for DESN368.

Design Decisions

What design choices did you make and why?

In this website design I really wanted to make the color palette and image aesthetics match the vibe of the outdoors and camping. I wanted the design choices to feel like they belonged out in the wilderness. The simple warm tones add to the feeling of the calming peaceful outdoors.

Technical Challenges

What was difficult to code? How did you solve it?

The most challenging piece was the CSS-only hamburger menu. Using a hidden checkbox input paired with a label and a sibling CSS selector to toggle the sidebar on mobile was an entirely new pattern. Getting the specificity right — and ensuring the sidebar animated in and out — took significant trial and error. The breakthrough was understanding that CSS can only select forward siblings, which shaped how I had to structure the HTML.

Responsive Strategy

How did you adapt your design for mobile?

The central responsive challenge was the sidebar. A fixed sidebar works beautifully on desktop but consumes too much screen space on mobile. My solution was to slide it off-screen by default and animate it back into view when the hamburger is checked. This preserves the sidebar's visual identity while keeping it out of the way until needed.

Learning Moments

What did you learn about Flexbox or CSS positioning?

Flexbox was the single biggest conceptual leap in this project. Early on I kept trying to style flex items directly to achieve layout effects that only work on the flex container. Understanding that properties like justify-content and align-items live on the parent — and that flex children are controlled by that parent — completely changed how I approach layout problems.

Future Improvements

What would you add or change with more time?

The most meaningful improvement would be scroll-triggered animations. Right now the page loads statically — sections simply exist. With more time I would explore ways to have each section fade in as the user scrolls to it, making the experience feel more like turning pages in a real field guide. The content deserves that kind of pacing.
